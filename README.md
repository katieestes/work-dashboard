# Work Dashboard

A personal work dashboard in a single HTML file. Open it in Chrome and it works offline. No installs and no build step, and it never connects to the internet.

## Features

- **Time clock**: clock in and out, take breaks, see hours worked, and get "you can leave at" times for 8, 8.5, 9, 9.5 and 10 hours
- **Hours chart**: this week compared with the week before
- **Daily objectives**: unfinished items can be carried forward to the next day
- **Wins log**: record accomplishments by category
- **Meetings**: recurring meeting rules (weekly, every N weeks, monthly) plus one-off meetings
- **Notes**: daily notes plus long-lived sticky notes
- **1:1 report generator**: monthly or quarterly summaries you can copy or print
- **History and search** across all days
- **Extras**: quote of the day, KJV verse of the day, quick links, GitLab quick open, countdowns, focus timer, snippets
- **8 color themes**

## Use it

1. Download `dashboard.html` (open the file, click **Raw**, then press **Ctrl+S**).
2. Save it somewhere permanent and double-click it to open it in Chrome.
3. Optional: to make it your startup page, go to Chrome **Settings → On startup → Open a specific page** and paste the file's address (`file:///...`).

## Your data

Everything you enter is saved in your browser's local storage on your own computer. Nothing is stored in this file or sent anywhere. Use **Export** in the sidebar to download a backup now and then.
